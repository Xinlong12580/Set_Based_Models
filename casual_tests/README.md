# Current trainer and examples

Run commands from the repository root.

| File | Purpose |
| --- | --- |
| `train_ERL.py` | Train one scalar configuration and save its unpruned model and report; reusable by other drivers. |
| `train_ERL_validation.py` | Single-run wrapper calling the trainer and validator with independent beam/pruning scores. |
| `validate_ERL.py` | Merge saved models, refresh validation statistics, and apply independent final pruning settings. |
| `scan_ERL.py` | Expand beam parameter lists, call the trainer per combination, save the manifest, then validate; [usage](ERL_SCAN.md). |
| `run_EDT_event_only.py` | Event-only EDT runner; requires the optional EDT extension. |
| `run_mixed_observables.py` | Small synthetic example; demonstrates ERL and, when installed, EDT. |
| `_erl_common.py` | Reference-penalized Gini score and shared ERL argument helpers. |
| `erl_scores.py` | External regularized excess/acceptance scores, score factory and report metadata. |
| `_erl_reporting.py` | Tensor loading and ERL rule/report construction shared by the trainer and validator. |
| `_erl_progress.py` | Optional ERL progress display. |
| `_quantitative_reporting.py`, `_event_only_reporting.py` | Shared schemas, metrics, CLI helpers, and report writers. |
| `_edt_reporting.py` | EDT-only report assembly, imported lazily. |

The current ERL runner does not import anything from `stale/`. Its search
implementation remains in `src/set_based_models/rule_list/`; this directory
provides study configuration and reporting, not a second copy of the algorithm.

```bash
python casual_tests/train_ERL.py --help
python casual_tests/run_EDT_event_only.py --help
python casual_tests/run_mixed_observables.py
```

Use `--event-only` on the current ERL runner instead of an older event-only
runner. See [ERL_GINI_INPUT_MODES.md](ERL_GINI_INPUT_MODES.md) for input selection,
priorities, scoring, and pruning options, and the repository README for the
complete conversion-to-training workflow.

For validation-based final selection, see [ERL_VALIDATION.md](ERL_VALIDATION.md).
This wrapper accepts one configuration and does not run final pruning on training
inputs. Use `--beam-reference-penalty` and `--pruning-reference-penalty` for the two scores.

All current ERL entry points accept `--score gini|excess|ratio`. The acceptance
scores use `--score-delta` / `--delta` (default 0.001). Wrappers can override the
validation choice separately. See the [scoring guide](../docs/ERL_SCORING.md)
for formulas, scanning and rescoring existing models.

For multiple search configurations and separate beam/final similarity thresholds,
see [ERL_SCAN.md](ERL_SCAN.md). Training and validation also run independently.

Training writes paired `.training.model.json` and `.training.report.json` files under
`training_outputs/`. Use `--output-prefix` to name both, or `--model` and
`--training-report` for individual paths. `--report` remains an alias for
`--training-report`; `--overwrite-output` permits replacing both outputs.
The dedicated trainer formerly named `train_ERL_scan.py` is now `train_ERL.py`.
The previous train-and-prune-on-training implementation is preserved under
`stale/train_ERL_pruned.py`. Existing saved results have not been renamed.

Superseded runners, their documentation, old console logs, sample data, and
generated bytecode were moved to [stale/](stale/README.md), not deleted.
